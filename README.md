# 📝 ngTask

O **ngTask** é uma aplicação de gerenciamento de tarefas (To-Do List) desenvolvida com **Angular**. O projeto foi criado para ser leve, intuitivo e funcional, servindo como uma excelente base para estudos de CRUD e gerenciamento de estado no ecossistema Angular.

---

## 🚀 Funcionalidades

* **Adicionar Tarefas:** Insira novas atividades com descrição.
* **Status de Conclusão:** Alterne entre tarefas pendentes e concluídas com um clique.
* **Remover Itens:** Exclua tarefas individuais de forma simples.
* **Contador:** Visualize o total de tarefas pendentes em tempo real.
* **Persistência Local:** (Opcional) Salva suas tarefas no `localStorage` do navegador.
